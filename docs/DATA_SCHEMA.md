# Spreadsheet schema

Every tab has a header row (row 1). Column **`id`** is a unique id generated by the app.
Columns are matched **by header name**, so you can reorder columns or add your own extra columns safely.
Booleans are `TRUE`/`FALSE`, dates are `YYYY-MM-DD`, months are `YYYY-MM`, money is a plain number in taka.
Values are written in RAW mode, so text that starts with `=` is stored as text, never run as a formula.

| Tab | Columns | Relationships |
|---|---|---|
| **Job Applications** | id, company, title, url, appliedDate, status, notes, createdAt, updatedAt | `status` ∈ toapply, applied, interviewing, assessment, offer, rejected, noresponse, withdrawn |
| **Skills** | id, name, why, project, order, createdAt | — |
| **Topics** | id, skillId, name, done, order | `skillId` → Skills.id. `done` is only used when the topic has no subtopics |
| **Subtopics** | id, topicId, skillId, name, done, order | `topicId` → Topics.id, `skillId` → Skills.id |
| Practice Counters | id, label, value, target | — |
| Goals | id, name, area, state, start, due, focus, useBudget, useTime, saved, monthly, running, hoursEst, weekly, deps, why, risk, resources, createdAt | `deps` = comma-separated Goals.id |
| Goal Budget Lines | id, goalId, label, amount, order | `goalId` → Goals.id |
| Milestones | id, goalId, text, done, order | `goalId` → Goals.id |
| Goal Deposits | id, goalId, date, amount | `goalId` → Goals.id |
| Time Log | id, goalId, date, hours | `goalId` → Goals.id |
| Tasks | id, title, goalId, status, priority, due, hours, dependsOn, blocked, doneAt, createdAt | `goalId` → Goals.id, `dependsOn` → Tasks.id |
| Wallets | id, name, kind, opening, order | — |
| Transactions | id, date, desc, amount, kind, category, walletId, toWalletId, createdAt | `kind` ∈ out, in, move. `walletId`/`toWalletId` → Wallets.id |
| Budgets | id, name, order | — |
| Budget Lines | id, budgetId, label, amount, order | `budgetId` → Budgets.id. `amount` is text such as `120k` |
| Reminders | id, title, date, kind, repeat, amount, walletId, leadDays, lastDone, done | `repeat` ∈ none, monthly, yearly |
| Content | id, title, platform, stage, date, views | — |
| Decisions | id, date, title, why, expect, reviewDate, outcome | — |
| Planned Expenses | id, label, amount, order | the monthly plan |
| Settings | id, value | keys: income, inflation, weeklyHours, emMonths, emSaved, emMonthly |

## Progress is calculated, not stored

Skill progress = completed items ÷ all items, where each **subtopic** is one item and a topic **without
subtopics** is one item (its own `done`). A topic is *Not Started* (0), *In Progress* (some) or *Completed*
(all). Nothing derived is stored, so editing the sheet by hand can never leave progress out of date.

## Deleting

Deleting a skill also deletes its topics and subtopics; deleting a topic deletes its subtopics; deleting a goal
deletes its budget lines, milestones, deposits and time log; deleting a budget deletes its lines.
